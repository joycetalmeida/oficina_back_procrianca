# Dia 1 - API basica + fetch no frontend

## Objetivo
Criar a primeira API com Node.js e conectar com um frontend simples em HTML/CSS/JS.

## O que sera construido
- Backend com endpoints de leitura
- Frontend com botao que busca dados da API

## Comandos
1. `cd backend`
2. `npm install`
3. `npm run dev`
4. Abrir `../frontend/index.html`

## Endpoints
- `GET /`
- `GET /status`
- `GET /cursos`
