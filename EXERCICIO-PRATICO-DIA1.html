Mão na massa - Criar o endpoint GET /instrutores

Abra o arquivo dia1-api-basica/backend/server.js e adicione um novo endpoint que retorna uma lista de instrutores.

Requisitos obrigatórios:

  • Criar um array instrutores com pelo menos 2 objetos.
  • Cada instrutor deve ter os campos: id, nome, especialidade.
  • O endpoint deve responder em GET /instrutores.
  • Testar no navegador: http://localhost:3333/instrutores.
Lembre-se: o servidor reinicia automaticamente quando você salvar o arquivo (nodemon). Não precisa parar e subir de novo.

5

Checklist de entrega

  • Servidor subindo sem erro com npm run dev.
  • GET / retornando JSON no browser.
  • GET /status retornando { status: "ok", horário: "..." }.
  • GET /cursos retornando array de cursos.
  • GET /instrutores criado e retornando dados.
  • Frontend carregando cursos e instrutores ao clicar nos botões.
  • Mensagem de erro aparecendo quando a API está offline.
  • Sem erros de console além do esperado quando API está offline.

Nível avançado - para quem terminar antes

  1. Filtro por nível: Criar endpoint GET /cursos?nivel=iniciante que filtra o array pelo query parameter.
    Dica: use req.query.nivel no handler da rota.
  2. Loading state: Desabilitar o botão enquanto o fetch está em andamento e habilitá-lo ao terminar.
    Dica: btnCarregar.disabled = true antes do fetch, false no finally.
  3. Contador: Exibir na tela quantos cursos foram retornados: "3 cursos encontrados".
